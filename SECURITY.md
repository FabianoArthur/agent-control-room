# Security policy

Agent Control Room is a static, client-only app: no backend, no accounts, no API keys, and it
stores only your theme preference in `localStorage`.

If you find a security issue (for example an XSS vector or a problem in the build or CI setup),
please report it privately through
[GitHub security advisories](https://github.com/FabianoArthur/agent-control-room/security/advisories/new)
instead of opening a public issue. I will reply as soon as I can.

Only the latest version on `main` is supported.
